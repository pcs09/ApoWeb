Gerador de Curriculos em PHP!

Este é um Gerador de Curriculos em PHP, com uma interface em HTML5 e CSS3, feito para a atividade de APO da Matéria de Fundamentos de Programação para Internet, do Curso de Análise e Desenvolvimentos de Sistemas da Universidade Unipar.

Para este gerador de curriculos em PHP, estou usando uma interface com html5 e css3, além JavaScript e jQuery para criar campos dinamicos e responsivos.

O ambiente utilizado para testes é o Xampp e usarei tecnicas de Git e Versionamento para o projeto em meu repositótio GitHub.
